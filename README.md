# ATOMSK + LAMMPS + OVITO Studio

Настольное приложение для молекулярно-динамического моделирования одноосного
растяжения поликристаллических металлов. ATOMSK строит поликристалл методом
Вороного, LAMMPS считает растяжение на EAM-потенциалах, OVITO рендерит
структуру по зернам, а приложение собирает отчет `.docx` с кривыми σ–ε,
модулем Юнга и максимальным напряжением.

Этот репозиторий хранит только установщики. Скачать: раздел
[Releases](https://github.com/dvdev-ai/atomsk-lammps-ovito-studio-releases/releases/latest).

| Система | Файл |
|---|---|
| macOS 13+, Apple Silicon (M1 и новее) | `ATOMSK-LAMMPS-OVITO-Studio-0.2.0-mac-arm64.dmg` |
| Windows 10 и 11, 64 бит | `ATOMSK-LAMMPS-OVITO-Studio-Setup-0.2.0.exe` |

ATOMSK, LAMMPS и OVITO уже внутри. Python, Homebrew и интернет не нужны.

## Установка на Mac

1. Открыть `.dmg`, перетащить приложение в «Программы».
2. Приложение не подписано Apple Developer ID. Первый запуск: правый клик,
   «Открыть», затем «Открыть» в диалоге. На macOS 15 и новее: «Системные
   настройки», «Конфиденциальность и безопасность», «Все равно открыть».

## Установка на Windows

1. Запустить `Setup.exe`. Установщик не подписан, Windows покажет «Windows
   защитила ваш компьютер»: «Подробнее», затем «Выполнить в любом случае».
2. Права администратора не нужны, приложение ставится в профиль пользователя.
   Окно рисует Microsoft Edge WebView2; если его нет, установщик поставит сам.

## Что умеет

- Материалы Cu, Al, Ni, Fe; температуры, размер ячейки, число зерен, скорость
  деформации и число шагов задаются в интерфейсе.
- Оценка числа атомов и времени до запуска, калибровка по прогонам на этой машине.
- Живой прогресс по термо-выводу LAMMPS, остановка без потери посчитанного.
- Кэш: расчет с теми же параметрами не повторяется.
- Отчет `.docx`: графики σ–ε, рендеры OVITO, таблица с модулем Юнга и
  максимальным напряжением.
- Самопроверка установки: запуск с ключом `--selftest`.
